    About This Project

    Dhaka City Building Height Analysis using Deep Learning

    AI Technology

    Uses YOLOv8 (You Only Look Once) deep learning model for real-time building instance segmentation and height classification.

    Classification

    Buildings are classified into three categories: Low-rise (1-4 floors), Mid-rise (5-12 floors), and High-rise (13+ floors).

    Dataset

    Trained on a custom dataset of annotated aerial and drone images of Dhaka City using YOLO segmentation format.

    Objective

    To assist urban planners, architects, and researchers in understanding Dhaka's building density and height distribution.

    Technology Stack

    Python 3.14 YOLOv8 (Ultralytics) FastAPI OpenCV PyTorch HTML / CSS / JavaScript Chart.js Lucide Icons

    Smart Dhaka 2035 Roadmap

    High-rise (15–30+ floors) strictly incentivized within 500m radius of MRT Line 6, Line 1, and Line 5 stations. Mid-rise (5–8 floors) as buffer zones connecting residential sectors. Low-rise zones preserved near peripheral rivers (Buriganga, Turag, Balu, Shitalakshya) and retention wetlands.

    Every high-rise and mid-rise development must implement rainwater harvesting and permeable ground paving. Protect and restore Dhaka's 43 historical khals (canals) as natural cooling corridors. Ground permeability of minimum 25% mandated for all new large developments.

    High-rises must integrate automatic gas and electric cut-off valves triggered by seismic P-wave detectors. Mandatory soil liquefaction testing (Micro-Zonation Audits) before RAJUK high-rise permits in reclamation zones. City-wide smart sensor network for real-time structural health monitoring.

    Real-time monitoring using drone/satellite imagery and computer vision to detect unauthorized vertical expansions without manual RAJUK field inspection. AI-powered permit processing with instant cross-check against DAP 2022–2035 zoning regulations. Blockchain-based building permit ledger for transparent governance.

    Mandatory green roofs or solar panels on all buildings above 5 floors. Building envelopes must achieve minimum 3-star GRIHA rating by 2030. Passive cooling design (natural cross-ventilation corridors) enforced in all new mid-rise clusters in Mirpur, Mohammadpur, and Rayer Bazar.
